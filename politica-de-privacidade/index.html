Politica de Privacidade

Aplicativo: Ear Training Lab

Controlador: Bruno Vieira

Contato: suporte@eartraininglab.com.br

Ultima atualizacao: 06/06/2026

1. Dados coletados

O app pode coletar dados de conta, perfil e uso necessarios para funcionamento do servico, incluindo email, nome, pais, cidade, genero, data de nascimento, instrumento principal, nivel de experiencia, progresso nos treinos, estatisticas de desempenho, estado de assinatura e eventos tecnicos de erro ou sincronizacao.

2. Finalidades

Usamos os dados para criar e autenticar contas, sincronizar progresso entre dispositivos, personalizar a experiencia, liberar recursos premium, processar assinaturas, melhorar estabilidade e atender solicitacoes de suporte, privacidade e exclusao de dados.

3. Base legal e consentimento

Dados essenciais de conta, perfil, progresso e assinatura sao tratados para execucao do servico solicitado pelo usuario. Estatisticas opcionais e dados de melhoria podem depender de consentimento ou configuracao do usuario no app, quando aplicavel.

4. Compartilhamento com fornecedores

Podemos usar fornecedores para operar o app, incluindo Supabase para autenticacao e banco de dados, RevenueCat e Google Play para assinaturas, Resend para envio de emails transacionais e servicos de diagnostico quando ativados. Esses fornecedores devem tratar dados conforme suas proprias politicas e conforme as instrucoes necessarias para prestacao do servico.

5. Armazenamento e seguranca

O app usa armazenamento local no dispositivo e sincronizacao em nuvem. Tokens de sessao devem ser armazenados de forma segura no dispositivo. O banco remoto usa politicas de acesso por usuario para reduzir acesso indevido.

6. Retencao

Dados de conta e progresso sao mantidos enquanto a conta estiver ativa. Apos solicitacao de exclusao, removeremos ou anonimizaremos dados pessoais em prazo razoavel, salvo quando a manutencao for necessaria para cumprimento legal, prevencao de fraude, seguranca ou registros transacionais.

7. Direitos do titular

Voce pode solicitar confirmacao de tratamento, acesso, correcao, exclusao, portabilidade, informacoes sobre compartilhamento e revogacao de consentimento quando aplicavel. Envie a solicitacao para suporte@eartraininglab.com.br.

8. Exclusao de conta

Para solicitar exclusao de conta e dados, acesse https://www.eartraininglab.com.br/excluir-conta ou envie email para suporte@eartraininglab.com.br usando o email cadastrado no app.

9. Alteracoes

Esta politica pode ser atualizada para refletir mudancas no app, fornecedores, requisitos legais ou praticas operacionais. A versao publicada nesta pagina sera a referencia vigente.
